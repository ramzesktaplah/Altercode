### 📋 Detailed Extended Release Notes
```text
AlterCode v2.7 Release Notes

What's New:
1. Enhanced Mobile Code Editor
   - Upgraded editor UI built with Jetpack Compose.
   - Built-in syntax highlighting tailored for comfortable viewing on mobile screens.
   - Improved gesture navigation, language pickers, and language badges.

2. Expanded Multi-Language Support
   - Convert, refactor, explain, and fix code in Kotlin, Python, TypeScript, Rust, Go, C++, Swift, Java, C#, PHP, JavaScript, and more.
   - Idiomatic code generation tuned to each language's standard conventions.

3. Encrypted Offline Storage & Drafts
   - Store your code snippets and working drafts securely on your device.
   - Local data is protected using SQLCipher database encryption and Android EncryptedSharedPreferences.

4. Faster & More Reliable AI Capabilities
   - Multi-provider AI routing dynamically selects the best engine for your request (Groq for instant fixes/explanations, Gemini for complex code translation & generation).
   - Rate limiting and backend stability improvements ensure consistent availability.
```
