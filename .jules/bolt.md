## 2026-09-16 - Compose Node Allocation & Line Counting Optimization in Jetpack Compose Editor
**Learning:** In Jetpack Compose, generating separate `Text` composable nodes inside a `Column` loop for $N$ line numbers scales linearly $O(N)$ in Compose layout node hierarchy and measurement costs. Joining line numbers into a single multi-line `Text` composable reduces Compose nodes from $N$ to 1. Additionally, `String.lines()` allocates a `List<String>` and substring for every line on every recomposition/keystroke; using a single-pass `CharSequence.countLines()` eliminates temporary heap allocations.
**Action:** Avoid looping over line elements to emit individual `Text` nodes in line gutters; render joined string blocks in a single `Text` node and use single-pass non-allocating string search functions for editor stats.
