# Sentinel's Journal

## 2026-03-29 - Type Confusion and DoS via Malformed JSON Payloads in Proxy Worker
**Vulnerability:** Untrusted JSON payloads sent to `/v1/chat` in `functions/index.ts` could crash the Cloudflare Worker with unhandled `TypeError` exceptions. When `body` was `null` or a non-object primitive, destructuring caused a fatal crash. Non-array objects mimicking arrays with a `length` property (e.g. `{"length": 1}`) bypassed `!messages?.length` and crashed on `messages.every()`. Arrays with `null` elements or non-string contents triggered property-access crashes or bypassed length calculations (`sum + undefined` evaluating to `NaN`).
**Learning:** In TypeScript Cloudflare Workers, type assertions like `(await request.json()) as ClientRequest` do not perform runtime validation. Any mismatch between runtime JSON shape and TypeScript interfaces causes unexpected exceptions that propagate out of handlers unless guarded by runtime type assertions and top-level error boundaries.
**Prevention:** Always validate runtime types (`typeof body === "object" && body !== null`, `Array.isArray(messages)`, non-null element checks, `typeof m.content === "string"`) before destructuring or calling array iteration methods. Wrap request handlers in a top-level `try/catch` block that logs details securely server-side and returns a generic 500 JSON response without leaking stack traces.
